# Troubleshooting

## The app does not load

Confirm that you are serving the project over HTTP(S) rather than opening `index.html` directly with `file://`.

## Changes are not appearing after an update

A previous service-worker cache may still control the page. During development, inspect the browser's Application → Service Workers section, update the cache version, and reload.

## Offline mode does not work

First open the deployed application while online and allow the service worker to install. Then reload once before testing offline operation.

## Import fails

Check that:

- The file was generated by a compatible Tracerix version.
- The passphrase is correct.
- The file was not modified or truncated.
- The file is a supported Tracerix backup/export type.

A failed import should not replace the existing vault.

## Data appears missing

Make sure you are using the same browser profile/origin. IndexedDB is scoped to the browser origin, so different domains, ports, or browser profiles can have separate data stores.

## The passphrase is lost

There is no server-side password reset. If the passphrase cannot be recovered, an encrypted backup may not be decryptable.
