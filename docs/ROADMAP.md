# Roadmap

This roadmap describes direction rather than a fixed delivery schedule.

## Near term

- Expand automated validation of import/export schemas.
- Add broader browser compatibility testing.
- Improve feature-level test coverage.
- Formalize data-version migrations.
- Improve accessibility and keyboard navigation.

## Medium term

- Add a dedicated settings module.
- Add clearer backup version compatibility handling.
- Add optional encrypted vault migration tooling.
- Add automated end-to-end tests for core workflows.

## Principles for future features

New functionality should preserve the project's core priorities: local ownership, minimal interaction, privacy, offline operation, reliable recovery, and avoidance of unnecessary gamification.
