# Feature Modules

Each directory in this folder represents a user-facing Tracerix capability.

- `daily-habits/` — regular daily habits and measurements
- `finite-goals/` — goals with a defined endpoint
- `infinite-skills/` — ongoing skills/practice
- `negative-habits/` — neutral personal behavior records
- `daily-notes/` — daily free-text notes
- `history/` — historical habit views
- `management/` — tracker configuration
- `backups/` — encrypted backup/import/export

Keep feature-specific logic inside its feature directory whenever practical.
