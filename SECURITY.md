# Security Policy

## Supported versions

Security fixes are prioritized for the current development version and the latest published release.

## Reporting a vulnerability

Please do not publish sensitive vulnerability details in a public issue.

Until a dedicated security contact is configured for this repository, use a private GitHub security advisory if the repository supports it. Otherwise, contact the project maintainer privately through the repository's configured contact method.

Include:

- A clear description of the issue.
- Affected file/module or feature.
- Reproduction steps.
- Security impact.
- Any suggested mitigation.

Do not include real personal tracker data, passphrases, or backup files in reports.
